# TDD Discount Calculator

Starter workspace for [Lab 2.1 – TDD: Red-Green-Refactor](../labs/2.1-tdd-red-green-refactor.md).

Pick **one** language track:

| Track | Folder | Install | Run tests |
|-------|--------|---------|-----------|
| Python | `python/` | `pip install -r requirements.txt` | `python -m pytest -v` |
| JavaScript | `javascript/` | `npm install` | `npm test` |

This code is **separate** from the BookNook app. It's built test-first, from scratch, by you.
